# GitHub 设置面板清空按钮右边距修复

## 问题

清空按钮的右边距比仓库输入框小，因为 flex 行的父级 div 没有设置 `width: 100%`。

## 修改

**文件**：`src/pages/editor.astro` line 1282

给 Token 行的父级 `<div>` 加 `w-full`：

```diff
- <div><label class="block text-xs font-medium text-black/60 dark:text-white/60 mb-1.5">GitHub Token</label><div class="flex gap-2">
+ <div class="w-full"><label class="block text-xs font-medium text-black/60 dark:text-white/60 mb-1.5">GitHub Token</label><div class="flex gap-2">
```

## 验证

`pnpm dev`，打开 GitHub 设置面板，确认清空按钮和仓库输入框右边距对齐。
