# 语法面板 tags 栏右边距调试

## 目标

在 tags 栏末尾添加多个测试标签，填满一整行，直观验证右边距大小。

## 修改

**文件**：`src/pages/editor.astro`，`renderSyntaxContent()` 函数

将已有的单个 TEST 标签替换为多个测试标签，填满一行：

```js
for (var ti = 0; ti < 5; ti++) {
  tagsHtml += '<span style="padding:3px 10px;border-radius:12px;font-size:12px;background:red;color:white;">T' + (ti+1) + '</span>';
}
```

测试完后删除整个 for 循环。
